# Отложенные требования других этапов

Создан 2026-10-31 на этапе «PROFESSIONAL HARDWARE 3D + DRILLING + BAZIS» (PART 13 задания владельца).
Порядок по решению владельца такой. Сначала завершается фурнитура, присадка и БАЗИС. Потом исправляются пункты
этого списка, если они не мешают фурнитуре. После них идёт отдельный этап SaaS PRODUCTION READINESS (ниже).

Статус каждого пункта — то, что известно о нём на дату записи. Пункт закрывается приёмкой с числами,
а не отметкой в этом файле.

## SaaS PRODUCTION READINESS — следующий отдельный этап, пока не начинать

Что в него входит:

- регистрация компаний, вход сотрудников, восстановление пароля;
- разделение компаний, роли владельца и сотрудников, изоляция данных, проверка Supabase RLS;
- безопасность файлов и выгрузок;
- тарифы, ограничения подписок, оплата;
- журнал действий, резервное копирование, мониторинг ошибок, производительность;
- подготовка коммерческого запуска.

Рекламу не запускать. Продукт не объявлять готовым, пока не завершены технические и производственные проверки.
