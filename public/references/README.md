# Каталог референсов материалов

Положите изображения образцов сюда, по папкам-категориям:

```
public/references/
  floor/     oak-herringbone.jpg
  wall/      porcelain-marble.jpg
  furniture/ boucle-sand.jpg
  textile/   linen-curtain.jpg
  decor/     ceramic-vase.jpg
```

Поддерживаются `.jpg`, `.jpeg`, `.png`, `.webp`. Имя файла превращается в
подпись: `oak-herringbone.jpg` → «Пол: Oak herringbone».

После добавления файлов пересоберите манифест:

```bash
npm run refs
```

Он же запускается автоматически в `prebuild`.

Референсы **опциональны**: с пустой папкой рендер работает по текстовому
описанию материалов из пресета стиля. Но когда у клиента есть свой каталог
(керамогранит, бамбуковые панели, ламинат), именно эти файлы превращают
«красивую картинку» в «мой товар на моей стене».

Модели уходит не больше `MAX_REFERENCES_PER_RENDER` образцов за раз —
на большем количестве она начинает путать их между собой.
